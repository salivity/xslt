Unnesting Arrays with array:flatten in XSLT 3.0

This article explains the purpose, operation, and practical utility of the array:flatten() function in XSLT 3.0 and XPath 3.1. It covers how the function recursively unpacks nested multidimensional arrays into a single, flat sequence of items, resolving structural complexities when transforming JSON structures and deeply nested hierarchical data.

The Purpose of array:flatten()

In XPath and XSLT, standard sequences cannot be nested; any sequence of sequences automatically collapses into a flat list of items. However, XSLT 3.0 (leveraging XPath 3.1) introduced arrays as first-class items, allowing them to contain other arrays and maintain nested structures.

The primary purpose of the array:flatten() function is to completely unnest multidimensional or recursively nested arrays, converting their members into a single, linear XPath sequence of non-array items.

How array:flatten() Works

The function takes any sequence of items—most commonly a single multidimensional array—as its input. It then processes the input recursively:

  1. It inspects every item in the provided sequence.
  2. If an item is an array, array:flatten() unpacks it and inspects all members within that array.
  3. If any of those members are also arrays, it continues unpacking them until no arrays remain.
  4. Any non-array items (such as atomic values, maps, or XML nodes) are returned in their original order as a standard, flat XPath sequence.

For example, consider the following multidimensional array:

array:flatten([1, [2, 3], [[4, 5], 6]])

Evaluating this expression results in a flat sequence:

(1, 2, 3, 4, 5, 6)

array:flatten() vs. Array Lookup (?*)

While the array lookup operator ?* can unpack an array, it only unwraps a single layer of nesting. If an array contains other arrays, ?* returns a sequence that still includes the inner array structures intact.

In contrast, array:flatten() is strictly recursive. It processes all levels of nesting regardless of depth, ensuring that the returned result contains zero array wrappers.

Common Use Cases

The most frequent application of array:flatten() is handling JSON data parsed using fn:json-doc() or fn:parse-json(). JSON data often features matrix-like structures, arbitrarily nested lists, or multi-tiered groupings.

Using array:flatten() allows developers to:

  • Extract all leaf values across arbitrary depths into a flat sequence for aggregation functions like sum(), avg(), or distinct-values().
  • Feed all array items directly into an xsl:for-each or xsl:apply-templates instruction without writing manual recursive template functions to unwrap each level.
  • Eliminate empty nested arrays without manual conditional filtering.
