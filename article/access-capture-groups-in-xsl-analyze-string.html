Access Capture Groups in xsl:analyze-string

This article explains how to capture and retrieve specific parts of a regular expression match using the <xsl:analyze-string> instruction in XSLT 2.0 and later versions. By utilizing the built-in regex-group() function within the <xsl:matching-substring> element, developers can isolate matched sub-expressions and transform parsed text nodes directly into structured XML elements.

Understanding <xsl:analyze-string>

The <xsl:analyze-string> instruction applies a regular expression to an input string, splitting it into matching and non-matching parts represented by two child instructions:

  • <xsl:matching-substring>: Processes segments of text that match the regex pattern.
  • <xsl:non-matching-substring>: Processes segments of text that do not match the regex pattern.

Using the regex-group() Function

To retrieve parenthesized capture groups defined inside the regex attribute, call the regex-group($n) function inside <xsl:matching-substring>.

  • regex-group(0) returns the entire substring matched by the complete regular expression.
  • regex-group(1) returns the text matched by the first parenthesized capture group ().
  • regex-group(2) returns the text matched by the second capture group, and so on.
  • If a capture group did not participate in the match, regex-group($n) returns a zero-length string.

Code Example

Consider an input string containing formatted dates such as 2023-11-15. The objective is to extract the year, month, and day into individual XML elements.

<xsl:analyze-string select="'Date: 2023-11-15'" regex="([0-9]{4})-([0-9]{2})-([0-9]{2})">
    <xsl:matching-substring>
        <date>
            <full-match><xsl:value-of select="regex-group(0)"/></full-match>
            <year><xsl:value-of select="regex-group(1)"/></year>
            <month><xsl:value-of select="regex-group(2)"/></month>
            <day><xsl:value-of select="regex-group(3)"/></day>
        </date>
    </xsl:matching-substring>
    <xsl:non-matching-substring>
        <xsl:value-of select="."/>
    </xsl:non-matching-substring>
</xsl:analyze-string>

Resulting Output

The execution of the template above transforms the matched segment into the following XML structure:

Date: <date>
    <full-match>2023-11-15</full-match>
    <year>2023</year>
    <month>11</month>
    <day>15</day>
</date>

Key Considerations

  • Scope: The regex-group() function is only valid dynamically inside the <xsl:matching-substring> block. Invoking it outside this context or within <xsl:non-matching-substring> returns an empty string.
  • Non-Capturing Groups: If you use non-capturing groups (?:...) in your regular expression, they are ignored by the index numbering of regex-group(), ensuring that only explicit capture groups shift the numeric index.
  • Nested Groups: Numbering corresponds to the opening parenthesis of each capturing group from left to right.
