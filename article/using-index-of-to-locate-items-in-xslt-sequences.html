Using index-of() to Locate Items in XSLT Sequences

The index-of() function in XSLT and XPath is a built-in function designed to locate specific atomic items within a sequence and return their 1-based numerical positions. This article explains how index-of() works, details its syntax and behavior with multiple or missing matches, and demonstrates how to effectively apply it when processing sequence data in XSLT transformations.

What is the index-of() Function?

Introduced in XPath 2.0 and fully supported in modern XSLT versions (2.0 and 3.0), the index-of() function searches an input sequence for items that match a target value. It performs an equality comparison (eq) against each item in the sequence and returns an integer or sequence of integers representing the positions where matches occur.

Syntax and Parameters

The function has two main signatures:

fn:index-of($sequence as xs:anyAtomicType*, $search as xs:anyAtomicType) as xs:integer*
fn:index-of($sequence as xs:anyAtomicType*, $search as xs:anyAtomicType, $collation as xs:string) as xs:integer*
  • $sequence: The sequence of atomic values to search through.
  • $search: The specific atomic value you want to locate.
  • $collation (optional): A URI specifying the collation algorithm to use for string comparisons, which is useful for case-insensitive searches.

Key Behaviors of index-of()

  • 1-Based Indexing: Unlike zero-based programming languages, XPath and XSLT sequences begin at index 1. The first item in the sequence resides at position 1.
  • Multiple Matches: If the search item appears multiple times in the sequence, index-of() returns a sequence containing the indices of all occurrences in ascending order.
  • No Match Found: If the target item is not present in the sequence, the function returns an empty sequence (()).
  • Atomic Types Only: The function requires atomic types (e.g., strings, integers, dates). When working with nodes, you must first atomize them (e.g., by selecting node values or attributes rather than the node itself).

Practical Examples

Finding a Single Match

Locating an integer inside a numeric sequence:

index-of((10, 20, 30, 40, 50), 30)

Result: 3

Handling Multiple Occurrences

When an item appears more than once, every matching index is returned:

index-of(('apple', 'banana', 'cherry', 'banana'), 'banana')

Result: (2, 4)

To retrieve only the first occurrence, wrap the expression to select the first item of the resulting sequence:

index-of(('apple', 'banana', 'cherry', 'banana'), 'banana')[1]

Result: 2

Searching Node Sequences in XSLT

When processing XML documents, extract atomic values from elements or attributes before passing them to index-of():

<xsl:variable name="statuses" select="//order/@status/string()" />
<xsl:variable name="pendingIndices" select="index-of($statuses, 'pending')" />

This retrieves the positions of all orders where the @status attribute equals 'pending'.
