Matrix and Geometry Calculations in Pure XSLT

Performing advanced mathematical calculations such as matrix multiplication, coordinate transformations, and geometric projections in pure XSLT is entirely feasible without relying on external extensions. By leveraging XPath 2.0 or 3.0 functional capabilities—specifically sequences, recursive processing, and custom stylesheet functions (xsl:function)—developers can build robust mathematical engines directly within an XSLT pipeline. This guide demonstrates how to represent mathematical structures, implement core linear algebra operations, and apply geometric transformations directly in pure XSLT.

Representing Vectors and Matrices

In XSLT 2.0 and later versions, data can be structured using native sequences or typed XML fragments. While XML nodes (such as <vector><cell>1</cell></vector>) provide structural clarity, flat XPath sequences often deliver better computational performance.

A flat sequence can represent an \(M \times N\) matrix by storing rows sequentially:

  • 2D Vector \((x, y, 1)\): (x, y, 1)
  • \(3 \times 3\) Matrix (Row-Major): (m11, m12, m13, m21, m22, m23, m31, m32, m33)

Row indices can be calculated using zero-based or one-based formulas: \[\text{Index}(row, col) = (row - 1) \times N + col\]

Vector Operations

Geometric calculations rely heavily on vector operations such as dot products, vector addition, and normalization. Using xsl:function, a dot product of two vectors of equal length can be written succinctly:

<xsl:function name="math:dot-product" as="xs:double">
    <xsl:param name="v1" as="xs:double*"/>
    <xsl:param name="v2" as="xs:double*"/>
    <xsl:sequence select="sum(for $i in 1 to count($v1) return $v1[$i] * $v2[$i])"/>
</xsl:function>

Vector length (magnitude) can then be derived using the standard math:sqrt function:

<xsl:function name="math:vector-length" as="xs:double">
    <xsl:param name="v" as="xs:double*"/>
    <xsl:sequence select="math:sqrt(math:dot-product($v, $v))"/>
</xsl:function>

Matrix Multiplication

Matrix multiplication forms the foundation for combining multiple affine transformations (such as translation, rotation, and scaling) into a single transformation matrix.

To multiply an \(M \times K\) matrix by a \(K \times N\) matrix:

<xsl:function name="math:matrix-multiply" as="xs:double*">
    <xsl:param name="A" as="xs:double*"/>
    <xsl:param name="B" as="xs:double*"/>
    <xsl:param name="rowsA" as="xs:integer"/>
    <xsl:param name="colsA" as="xs:integer"/>
    <xsl:param name="colsB" as="xs:integer"/>

    <xsl:sequence select="
        for $r in 1 to $rowsA return
            for $c in 1 to $colsB return
                sum(
                    for $k in 1 to $colsA return
                        $A[($r - 1) * $colsA + $k] * $B[($k - 1) * $colsB + $c]
                )
    "/>
</xsl:function>

Geometric Affine Transformations

Homogeneous coordinates simplify 2D and 3D transformations by representing translations as matrix multiplications alongside rotations and scaling.

2D Transformation Matrices (3×3)

A standard 2D point \((x, y)\) is represented as the column vector \(\begin{bmatrix} x & y & 1 \end{bmatrix}^T\).

  1. Translation \((dx, dy)\):

    <xsl:variable name="T" select="(
    1, 0, $dx,
    0, 1, $dy,
    0, 0, 1
)"/>

  2. Scaling \((sx, sy)\):

    <xsl:variable name="S" select="(
    $sx, 0,   0,
    0,   $sy, 0,
    0,   0,   1
)"/>

  3. Rotation by angle \(\theta\) (in radians):

    <xsl:variable name="cosT" select="math:cos($theta)"/>
<xsl:variable name="sinT" select="math:sin($theta)"/>
<xsl:variable name="R" select="(
    $cosT, -$sinT, 0,
    $sinT,  $cosT, 0,
    0,      0,     1
)"/>

Transforming a Point

To transform a point by a transformation matrix, multiply the matrix by the vector representing the point:

<xsl:function name="math:transform-point-2d" as="xs:double*">
    <xsl:param name="matrix" as="xs:double*"/>
    <xsl:param name="point" as="xs:double*"/> <!-- (x, y) -->
    
    <xsl:variable name="p" select="($point[1], $point[2], 1.0)"/>
    <xsl:variable name="transformed" select="math:matrix-multiply($matrix, $p, 3, 3, 1)"/>
    <xsl:sequence select="($transformed[1], $transformed[2])"/>
</xsl:function>

Handling Trigonometry in XSLT 1.0

While XSLT 3.0 and XPath 3.0 offer native namespace functions like math:sin(), math:cos(), and math:sqrt(), legacy environments restricted to XSLT 1.0 must compute trigonometric functions using Taylor series expansions implemented via recursive named templates:

\[\sin(x) = \sum_{n=0}^{\infty} \frac{(-1)^n}{(2n+1)!} x^{2n+1} = x - \frac{x^3}{6} + \frac{x^5}{120} - \dots\]

<xsl:template name="approx-sin">
    <xsl:param name="x"/>
    <xsl:param name="term" select="$x"/>
    <xsl:param name="n" select="1"/>
    <xsl:param name="sum" select="$x"/>
    <xsl:choose>
        <xsl:when test="$n &gt; 10">
            <xsl:value-of select="$sum"/>
        </xsl:when>
        <xsl:otherwise>
            <xsl:variable name="next-term" select="-$term * $x * $x div ((2 * $n) * (2 * $n + 1))"/>
            <xsl:call-template name="approx-sin">
                <xsl:param name="x" select="$x"/>
                <xsl:param name="term" select="$next-term"/>
                <xsl:param name="n" select="$n + 1"/>
                <xsl:param name="sum" select="$sum + $next-term"/>
            </xsl:call-template>
        </xsl:otherwise>
    </xsl:choose>
</xsl:template>

Practical Application: SVG Coordinate Mapping

A primary use case for matrix mathematics in XSLT is dynamically generating and transforming SVG paths, graphs, or CAD coordinates directly from raw XML data. By chaining matrix multiplications into a combined viewport-to-canvas transform, coordinates can be converted, rotated, scaled, and translated in a single declarative step before the final XML/SVG markup is emitted.
