Standalone Attribute in XSLT XML Serialization

The standalone attribute in XSLT serialization specifies whether the generated XML document includes a standalone declaration in its XML prolog. This article explains the role of the standalone attribute in the <xsl:output> element, how it controls the serialization of the XML declaration, and how it informs XML parsers about external markup dependencies.

In XSLT, serialization is configured using the <xsl:output> element, which dictates how the result tree is converted into a byte or character stream. When using the xml output method, the standalone attribute accepts one of two values: "yes" or "no".

<xsl:output method="xml" standalone="yes" encoding="UTF-8" indent="yes"/>

When defined, the serializer writes the attribute directly into the XML declaration at the top of the output document:

<?xml version="1.0" encoding="UTF-8" standalone="yes"?>

Purpose and Parser Behavior

The primary function of the standalone declaration in the XML standard is to signal to validating and non-validating parsers whether the document depends on external markup declarations.

  • standalone="yes": Indicates that the document is completely self-contained. Any Document Type Definition (DTD) rules, entity definitions, or default attributes necessary for parsing the document are internal. An XML parser encountering this can safely parse the document without fetching or evaluating external DTD subsets or external parameter entities. This can prevent external network calls and optimize parsing performance.
  • standalone="no": Indicates that external declarations exist that may alter the interpretation of the document's content, such as providing default attribute values or defining general entities used in the content.
  • Omission: If the standalone attribute is omitted from <xsl:output>, the serializer typically generates an XML declaration without the standalone pseudo-attribute, leaving the determination to default parser behaviors.

Validity Constraints

According to the XML specification, setting standalone="yes" carries a validity constraint: external declarations must not define default attribute values or entities that appear in the document, nor can external tokenized attributes contain values subject to normalization. If an XSLT transformation outputs a DTD reference via doctype-system along with standalone="yes", the document will fail validation if the external DTD affects the document’s data content.

In modern XML architectures that rely on XML Schema (XSD) or RELAX NG rather than DTDs, the standalone declaration is rarely functional for validation, but it remains a required serialization parameter for systems adhering strictly to the XML 1.0 prolog requirements.
