Standard XSLT System Properties

The XSLT specification provides the system-property() function to retrieve metadata about the execution environment and the active XSLT processor. This article outlines the standard system properties defined across XSLT specifications—including core properties such as xsl:version and xsl:vendor, as well as extended properties introduced in XSLT 2.0 and XSLT 3.0—explaining what values they return and how they are used.

Core XSLT 1.0 System Properties

The W3C XSLT 1.0 specification defines three standard system properties in the XSLT namespace (http://www.w3.org/1999/XSL/Transform). Any conformant XSLT processor must implement these:

  • xsl:version: Returns a number representing the XSLT specification version implemented by the processor (for example, 1.0, 2.0, or 3.0).
  • xsl:vendor: Returns a string identifying the vendor or creator of the XSLT processor (for example, "Saxonica", "Apache Software Foundation", or "Microsoft").
  • xsl:vendor-url: Returns a string containing a URL identifying the processor vendor (for example, "http://www.saxonica.com/" or "http://xml.apache.org/xalan-j").

Properties Introduced in XSLT 2.0

XSLT 2.0 expanded the list of standard properties to provide more granular product details and capability indicators:

  • xsl:product-name: Returns the commercial or release name of the processor product (for example, "Saxon-PE").
  • xsl:product-version: Returns the version number of the software product itself (for example, "10.5").
  • xsl:is-schema-aware: Returns the string "yes" if the processor supports XML Schema processing and validation, or "no" if it is basic.
  • xsl:supports-serialization: Returns "yes" or "no" indicating whether the processor supports the standard serialization feature.
  • xsl:supports-backwards-compatibility: Returns "yes" or "no" indicating whether the processor supports running in XSLT 1.0 compatibility mode.

Properties Introduced in XSLT 3.0

XSLT 3.0 added further properties reflecting modern processor capabilities:

  • xsl:supports-dynamic-evaluation: Returns "yes" or "no" indicating support for dynamic XPath evaluation via the xsl:evaluate instruction.
  • xsl:xpath-version: Returns a decimal indicating the highest version of the XPath specification supported by the processor (for example, 3.1).
  • xsl:supports-streaming: Returns "yes" or "no" indicating whether the processor supports streaming transformations of XML documents.

Usage Syntax

Properties are queried using the system-property() XPath function, which accepts the qualified name (QName) of the property as a string argument:

<xsl:value-of select="system-property('xsl:version')"/>
<xsl:value-of select="system-property('xsl:vendor')"/>
<xsl:value-of select="system-property('xsl:product-name')"/>

Processors return an empty string if a queried property name is not recognized or unsupported.
