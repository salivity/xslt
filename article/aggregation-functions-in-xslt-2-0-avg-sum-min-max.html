Aggregation Functions in XSLT 2.0+: avg, sum, min, max

In XSLT 2.0 and later versions, the aggregation functions avg(), sum(), min(), and max() provide native mechanisms to calculate statistical metrics over sequences of items. Sourced from the shared XPath 2.0 function library, these functions eliminate the complex recursive templates that were required in XSLT 1.0. This article explains the purpose, behavior, and practical application of each of these four core aggregation functions when transforming XML documents.

Overview of Sequence Aggregation

XSLT 1.0 operated strictly on node-sets and offered only a basic sum() function that required implicit conversions to numbers. XSLT 2.0+ adopts the XPath 2.0 data model, which is built on sequences of atomic values and nodes. Aggregation functions in XSLT 2.0+ process a sequence of zero or more items, automatically "atomizing" nodes into their typed values (such as xs:integer, xs:decimal, xs:date, or xs:string) before performing calculations.

The sum() Function

The sum() function computes the arithmetic total of all values in an input sequence.

  • Purpose: Calculates the total of numeric values, dates, times, or durations.
  • Syntax: sum($arg as xs:anyAtomicType*) as xs:anyAtomicType or sum($arg, $zero)
  • Behavior:
    • If the sequence contains numeric items, they are added together using standard numeric promotion rules.
    • Unlike XSLT 1.0, XSLT 2.0 allows sum() to add year-month or day-time durations.
    • If the input sequence is empty, sum() returns the integer 0. An optional second argument allows you to specify an alternative fallback value for empty inputs (e.g., sum($items, ())).

The avg() Function

The avg() function calculates the arithmetic mean of a sequence of numeric or duration values.

  • Purpose: Determines the average value of a given dataset.
  • Syntax: avg($arg as xs:anyAtomicType*) as xs:anyAtomicType?
  • Behavior:
    • It divides the sum of the sequence items by the total number of items (fn:count($arg)).
    • If the items are of mixed numeric types (e.g., integers and doubles), values are promoted to a common type before calculation.
    • If the input sequence is empty, avg() returns an empty sequence (()), rather than 0 or NaN.

The min() and max() Functions

The min() and max() functions identify the extreme boundaries of a sequence based on type-specific ordering.

  • Purpose: Returns the minimum or maximum item from a sequence, respectively.
  • Syntax:
    • min($arg as xs:anyAtomicType*) as xs:anyAtomicType?
    • max($arg as xs:anyAtomicType*) as xs:anyAtomicType?
  • Behavior:
    • Numeric comparison: Evaluates numeric values to find the lowest or highest value.
    • String and URI comparison: Compares values lexicographically based on Unicode codepoints or a specified collation.
    • Dates and Durations: Identifies the earliest or latest date, time, or duration.
    • Both functions require all items in the sequence to be mutually comparable. Attempting to find the minimum of a mixed sequence of strings and numbers will result in a dynamic type error.
    • If the input sequence is empty, both functions return an empty sequence (()).

Summary of Use Cases

  • Use sum() when aggregating quantities, itemized invoices, or cumulative durations.
  • Use avg() when generating summary reports requiring mean metrics, such as average test scores or response times.
  • Use min() and max() to detect boundaries, such as finding the lowest product price, the latest modification date, or sorting alphabetic ranges.
