How to Insert Dynamic XML Comments Using xsl:comment

The <xsl:comment> element in XSLT generates standard XML or HTML comments (<!-- ... -->) in the final transformed output document. Rather than producing fixed, static text, <xsl:comment> processes its contents dynamically at runtime, allowing developers to inject variable data, source node values, calculation results, and timestamps directly into the generated comments.

The Mechanism of <xsl:comment>

In XSLT, the <xsl:comment> element instructs the XSLT processor to instantiate a comment node in the result tree. Because it is an XSLT instruction element rather than raw text, the processor parses and executes child elements placed inside it before writing the final string to the output document.

To generate dynamic content inside the comment, you can nest other XSLT instructions inside <xsl:comment>, including:

  • <xsl:value-of> to extract data from the source XML or compute XPath expressions.
  • <xsl:text> to manage whitespace and fixed labeling.
  • Control-flow elements such as <xsl:if> and <xsl:choose> to vary comment text conditionally.

Example Implementation

Consider a source XML document containing product data:

<product id="P102" status="discontinued">
    <name>Desk Lamp</name>
    <stock>0</stock>
</product>

To include dynamic processing details and metadata inside the output, the following XSLT template uses <xsl:comment>:

<xsl:template match="product">
    <xsl:comment>
        <xsl:text> Record ID: </xsl:text>
        <xsl:value-of select="@id" />
        <xsl:text> | Status: </xsl:text>
        <xsl:value-of select="@status" />
        <xsl:if test="@status = 'discontinued'">
            <xsl:text> (Needs cleanup) </xsl:text>
        </xsl:if>
    </xsl:comment>
    <item>
        <xsl:value-of select="name" />
    </item>
</xsl:template>

Output

When the transformation runs, the XSLT engine evaluates the XPath expressions and dynamic conditions, wrapping the resolved string in standard comment delimiters:

<!-- Record ID: P102 | Status: discontinued (Needs cleanup) -->
<item>Desk Lamp</item>

Key Technical Restrictions

When constructing dynamic comments with <xsl:comment>, the output content must conform to the W3C XML specification:

  1. No Double Hyphens: The string generated within the comment must not contain two consecutive hyphens (--). If an evaluated expression outputs --, compliant XSLT processors will either signal a serialization error or insert whitespace between the hyphens (e.g., - -).
  2. Trailing Hyphens: The generated text must not end with a hyphen (-), as this creates an illegal comment closure (--->).
  3. No Nested Elements in Output: While you can use XSLT instructions within <xsl:comment> during stylesheet execution, only text strings are serialized inside the comment tags in the resulting document. Dynamic XML element nodes generated within the comment are converted to their string values.
