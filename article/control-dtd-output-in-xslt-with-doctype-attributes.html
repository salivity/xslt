Control DTD Output in XSLT with Doctype Attributes

In XSLT, the doctype-public and doctype-system attributes of the <xsl:output> element control how a Document Type Declaration (DTD or <!DOCTYPE>) is generated in the final serialized document. By specifying one or both of these attributes, a developer instructs the XSLT processor to emit a standard public or private system DTD reference without manually writing DOCTYPE tags inside the transformation logic. This article explains how these two attributes interact, the syntax they produce in XML and HTML outputs, and the rules governing their behavior.

The Role of <xsl:output>

The <xsl:output> element defines the serialization parameters for the transformation result. When you need the output document to include a <!DOCTYPE> declaration, you configure doctype-system and doctype-public as top-level attributes inside this element.

The name of the root element in the generated <!DOCTYPE> declaration is automatically determined by the XSLT processor based on the first element created in the output document.

Using doctype-system Alone

The doctype-system attribute specifies a private or local URI pointing to the DTD file. When used without doctype-public, the processor generates a SYSTEM identifier.

XSLT Declaration:

<xsl:output method="xml" doctype-system="rules.dtd" indent="yes"/>

Resulting Output:

<!DOCTYPE root SYSTEM "rules.dtd">
<root>
  ...
</root>

Using Both doctype-public and doctype-system

When both attributes are present, the processor outputs a PUBLIC declaration containing both the formal public identifier (FPI) and the system URI fallback.

XSLT Declaration:

<xsl:output method="xml" 
            doctype-public="-//W3C//DTD XHTML 1.0 Strict//EN" 
            doctype-system="http://www.w3.org/TR/xhtml1/DTD/xhtml1-strict.dtd" 
            indent="yes"/>

Resulting Output:

<!DOCTYPE html PUBLIC "-//W3C//DTD XHTML 1.0 Strict//EN" "http://www.w3.org/TR/xhtml1/DTD/xhtml1-strict.dtd">
<html xmlns="http://www.w3.org/1999/xhtml">
  ...
</html>

Behavior When Only doctype-public Is Provided

The behavior for specifying only doctype-public depends on the output method:

  • XML Output (method="xml"): The XML standard requires that any external PUBLIC identifier must be accompanied by a system identifier. Consequently, if doctype-system is omitted in an XML transformation, most conforming XSLT processors will omit the <!DOCTYPE> declaration entirely or signal an error.
  • HTML Output (method="html"): Standard HTML allows a public identifier without a system URI. If doctype-public is specified alone with method="html", the processor outputs: 
    <!DOCTYPE HTML PUBLIC "public-id">

Summary of DOCTYPE Generation Rules

  1. Neither attribute set: No <!DOCTYPE> tag is emitted in the output.
  2. doctype-system only: Produces <!DOCTYPE root SYSTEM "system-uri">.
  3. doctype-public and doctype-system: Produces <!DOCTYPE root PUBLIC "public-id" "system-uri">.
  4. doctype-public only: Produces <!DOCTYPE HTML PUBLIC "public-id"> in HTML mode; ignored or invalid in XML mode.
