Remove Duplicates with distinct-values in XSLT 2.0

In XSLT 2.0, eliminating duplicate data from XML sources is streamlined through the native XPath function distinct-values(). Prior to XSLT 2.0, developers relied on complex patterns like Muenchian grouping to filter unique values. This article explains how distinct-values() works, demonstrates its implementation with practical code examples, and outlines best practices for handling unique datasets.

The Role of distinct-values()

The distinct-values() function takes a sequence of atomic values as input and returns a new sequence containing only the distinct (unique) values. Any item in the sequence that matches an earlier item—based on standard equality comparisons (eq)—is discarded.

The basic syntax is:

fn:distinct-values($arg as xdt:anyAtomicType*) as xdt:anyAtomicType*

Because it operates on atomic values, the function automatically atomizes node-sets into their string or typed values before evaluating uniqueness.

Eliminating Duplicates: A Practical Example

Consider an XML document containing a list of products where categories are repeated across multiple entries:

<catalog>
    <product>
        <name>Laptop</name>
        <category>Electronics</category>
    </product>
    <product>
        <name>Shirt</name>
        <category>Apparel</category>
    </product>
    <product>
        <name>Headphones</name>
        <category>Electronics</category>
    </product>
</catalog>

To extract a unique list of all categories, distinct-values() can be used inside an xsl:for-each loop:

<xsl:stylesheet version="2.0" xmlns:xsl="http://www.w3.org/1999/XSL/Transform">
    <xsl:output method="xml" indent="yes"/>

    <xsl:template match="/catalog">
        <categories>
            <xsl:for-each select="distinct-values(product/category)">
                <category><xsl:value-of select="."/></category>
            </xsl:for-each>
        </categories>
    </xsl:template>
</xsl:stylesheet>

The output contains only one instance of each category:

<categories>
    <category>Electronics</category>
    <category>Apparel</category>
</categories>

Key Considerations

  1. Loss of Node Identity: The distinct-values() function extracts raw values (such as strings or numbers) rather than retaining the original XML nodes or their attributes. If access to child nodes, parent elements, or attributes of the matched items is required, the xsl:for-each-group instruction using the group-by attribute is generally the better alternative.
  2. Type Sensitivity and Collation: Comparisons are type-aware. For string comparisons, distinct-values() allows an optional second argument specifying a collation URI to handle case sensitivity and locale-specific rules.
