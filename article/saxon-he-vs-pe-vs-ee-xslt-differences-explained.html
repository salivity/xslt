Saxon-HE vs PE vs EE: XSLT Differences Explained

Saxon is the standard reference processor for XSLT, XPath, and XQuery, available in three distinct tiers: Home Edition (HE), Professional Edition (PE), and Enterprise Edition (EE). While Saxon-HE provides an open-source implementation of basic XSLT 3.0 transformations, Saxon-PE introduces extensibility with custom Java/.NET functions and pre-compiled stylesheets. Saxon-EE represents the fully featured commercial tier, delivering advanced performance optimizations, streaming for massive datasets, schema-aware transformations, and bytecode generation.

Saxon-HE (Home Edition)

Saxon-HE is the free, open-source version licensed under the Mozilla Public License 2.0. It delivers complete conformance to the W3C XSLT 3.0, XQuery 3.1, and XPath 3.1 specifications for core transformation tasks.

  • Target Audience: Open-source projects, hobbyists, students, and applications with standard transformation workloads.
  • Key Capabilities: Standard-compliant processing for non-schema-aware transformations.
  • Limitations:
    • No support for schema-aware XSLT.
    • No execution of arbitrary Java or .NET extension functions (strictly limited to standard XPath functions and built-in Saxon extension functions).
    • No optimizer or bytecode compilation.
    • No XSLT 3.0 streaming for large files.

Saxon-PE (Professional Edition)

Saxon-PE is a commercially licensed tier designed for professional software development environments that require custom integration capabilities beyond standard W3C functions.

  • Target Audience: Developers needing custom business logic integration, proprietary extension functions, or distribution of pre-compiled transformation logic.
  • Key Capabilities Over Saxon-HE:
    • Reflexive Extension Functions: Full ability to bind and call external methods written in Java or .NET directly from XSLT code.
    • EXPath Support: Built-in support for EXPath modules, such as the File and Archive libraries.
    • Execution of Exported Stylesheets: Can execute compiled stylesheets (Saxon Export Format or .sef files) produced by Saxon-EE.
    • Enhanced Localization: Extended internationalization tools and language-specific collations.
  • Limitations:
    • Does not support XML Schema validation or schema-aware execution within transformations.
    • Does not include Enterprise optimization features like bytecode generation or streaming.

Saxon-EE (Enterprise Edition)

Saxon-EE is the high-performance, flagship commercial edition engineered for mission-critical enterprise workloads, high-throughput pipelines, and massive XML datasets.

  • Target Audience: Enterprise architectures handling high-volume transformations, ultra-large documents, or strictly validated data pipelines.
  • Key Capabilities Over Saxon-PE:
    • Schema-Aware Processing: Native support for XML Schema 1.0 and 1.1. Allows stylesheets to type-check nodes against a schema at compile time and runtime, catching structural errors early and optimizing execution paths.
    • Streaming Transformations: Full W3C XSLT 3.0 streaming capability, allowing multi-gigabyte XML files to be parsed, transformed, and output without loading the entire document tree into memory.
    • Bytecode Generation: Compiles hot execution paths in XSLT code directly into JVM or .NET bytecode on the fly, yielding dramatic execution speed improvements.
    • Stylesheet Exporting: Capability to compile XSLT source code into pre-compiled binary packages (.sef files) to protect intellectual property and eliminate compile-time overhead in production.
    • Advanced Optimizer: Multi-threaded processing capabilities, loop-unrolling, and advanced query-rewriting algorithms.
