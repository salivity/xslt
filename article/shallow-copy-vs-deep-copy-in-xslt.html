Shallow Copy vs Deep Copy in XSLT

In XSLT processing, copying XML nodes from an input document to the result tree is a fundamental operation accomplished through either a shallow copy or a deep copy. This article explains the technical differences between these two copying mechanisms, detailing how <xsl:copy> and <xsl:copy-of> function, how they handle node attributes and descendants, and when to apply each approach during XML transformations.

Deep Copy: <xsl:copy-of>

A deep copy in XSLT replicates a selected node along with all of its attributes, descendant elements, text nodes, comments, and processing instructions. It is executed using the <xsl:copy-of> element with a select attribute.

When you use <xsl:copy-of select="node"/>, the XSLT processor inserts an exact, recursive clone of the target subtree into the output document. Because the entire hierarchy is copied in a single operation, template rules cannot be applied to any child nodes within that subtree.

Key characteristics of <xsl:copy-of>:

  • Recursive: Copies the current node, all attributes, and all descendants down to the deepest leaf nodes.
  • Closed Operation: Cannot contain child instructions like <xsl:apply-templates> within its tags; it is an empty element (<xsl:copy-of select="..."/>).
  • Use Case: Best suited for moving large, unchanged chunks of XML from the source directly into the target document without modification.

Shallow Copy: <xsl:copy>

A shallow copy replicates only the current context node, deliberately omitting its attributes and descendant nodes. It is executed using the <xsl:copy> element, which acts on the current node in context rather than taking a select expression.

If the current node is an element, <xsl:copy> generates the opening and closing tags of that element in the result tree, but leaves the interior empty. To populate the copied element with attributes or child nodes, you must explicitly instruct the processor using nested instructions—most commonly <xsl:apply-templates select="@* | node()"/>.

Key characteristics of <xsl:copy>:

  • Non-recursive: Copies only the outermost node in the current context.
  • Open Container: Allows nested XSLT instructions between <xsl:copy> and </xsl:copy>, giving you full control over what goes inside the node.
  • Use Case: The backbone of the identity transformation pattern, where the goal is to reproduce an XML structure while modifying, filtering, or injecting specific attributes and child elements.

Summary of Differences

Feature Shallow Copy (<xsl:copy>) Deep Copy (<xsl:copy-of>)
Scope Current node only Current node, attributes, and all descendants
Attributes Not included (must be copied manually) Automatically included
Children Not included Automatically included
Customization High; contents can be filtered or changed None; outputs the subtree verbatim
Selection Syntax Operates on current context node Uses the select attribute to target nodes
