Datetime Manipulation in XSLT Using Durations

Modern XSLT (versions 2.0 and later) handles temporal data natively by leveraging the W3C XML Schema data types xs:dateTime, xs:date, and xs:duration. Through XPath 2.0 and 3.1 functions, XSLT provides robust tools to parse, extract, calculate, and format dates and times without relying on proprietary extensions or complex string manipulations.

Core Data Types

XSLT relies on standard ISO 8601 representations provided by XML Schema:

  • xs:dateTime: Represents a specific instant in time (e.g., 2023-10-31T09:30:00Z).
  • xs:date: Represents a calendar day (e.g., 2023-10-31).
  • xs:duration: Represents an elapsed span of time, split into two distinct, arithmetic-compatible subtypes:
    • xs:yearMonthDuration: Represents years and months (e.g., P1Y2M for 1 year and 2 months).
    • xs:dayTimeDuration: Represents days, hours, minutes, and seconds (e.g., P3DT4H30M for 3 days, 4 hours, and 30 minutes).

Arithmetic Operations with Dates and Durations

XSLT supports basic arithmetic operators (+ and -) for temporal values, provided the duration subtype matches the required precision.

1. Adding or Subtracting Durations

You can adjust an xs:dateTime or xs:date by adding or subtracting an xs:duration:

<!-- Adding 3 days to a date -->
<xsl:value-of select="xs:date('2023-10-01') + xs:dayTimeDuration('P3D')"/>
<!-- Output: 2023-10-04 -->

<!-- Subtracting 2 hours from a dateTime -->
<xsl:value-of select="xs:dateTime('2023-10-01T12:00:00Z') - xs:dayTimeDuration('PT2H')"/>
<!-- Output: 2023-10-01T10:00:00Z -->

<!-- Adding 6 months using xs:yearMonthDuration -->
<xsl:value-of select="xs:date('2023-01-15') + xs:yearMonthDuration('P6M')"/>
<!-- Output: 2023-07-15 -->

2. Calculating the Difference Between Two Dates

Subtracting one xs:date or xs:dateTime from another returns an xs:dayTimeDuration:

<xsl:value-of select="xs:date('2023-10-15') - xs:date('2023-10-10')"/>
<!-- Output: P5D -->

Extracting Components

XPath provides dedicated accessor functions to retrieve individual components from date and duration values:

  • From xs:dateTime or xs:date:
    • year-from-date($date) or year-from-dateTime($dt)
    • month-from-date($date) or month-from-dateTime($dt)
    • day-from-date($date) or day-from-dateTime($dt)
    • hours-from-dateTime($dt), minutes-from-dateTime($dt), seconds-from-dateTime($dt)
  • From xs:duration:
    • days-from-duration($dur), hours-from-duration($dur), minutes-from-duration($dur)

Example:

<xsl:variable name="current" select="xs:dateTime('2023-10-31T14:45:00')"/>
<year><xsl:value-of select="year-from-dateTime($current)"/></year> <!-- 2023 -->
<hour><xsl:value-of select="hours-from-dateTime($current)"/></hour> <!-- 14 -->

Formatting Dates and Times

To display dates in custom formats, XSLT provides format-date(), format-dateTime(), and format-time(). These functions take the value as the first argument and a picture string as the second:

<xsl:variable name="eventDate" select="xs:dateTime('2023-10-31T09:30:00')"/>

<!-- Format: Day/Month/Year -->
<xsl:value-of select="format-dateTime($eventDate, '[D01]/[M01]/[Y0001]')"/>
<!-- Output: 31/10/2023 -->

<!-- Format: Full Month Name, Day, Year -->
<xsl:value-of select="format-dateTime($eventDate, '[MNn] [D], [Y]')"/>
<!-- Output: October 31, 2023 -->

Comparing Values

Because xs:date, xs:dateTime, and duration subtypes are fully ordered types in XSLT, standard comparison operators (=, !=, <, <=, >, >=) can be used directly:

<xsl:if test="xs:date('2023-12-01') &gt; xs:date('2023-11-01')">
    <xsl:text>Future date</xsl:text>
</xsl:if>
