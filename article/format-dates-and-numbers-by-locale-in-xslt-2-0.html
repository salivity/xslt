Format Dates and Numbers by Locale in XSLT 2.0

XSLT 2.0 provides robust, built-in functions to display dates, times, and numeric data according to specific regional standards. By leveraging format-date() alongside format-number() and the top-level <xsl:decimal-format> declaration, developers can transform raw XML values into localized strings that respect language conventions, calendars, and punctuation preferences across different countries.

Formatting Numbers with format-number()

The format-number() function formats a numeric value as a string based on a picture pattern and an optional localized decimal format.

Syntax

format-number($value, $picture, $decimal-format-name?)

To adapt numbers to regional conventions (such as swapping commas and periods for thousands and decimal separators), declare an <xsl:decimal-format> element.

Example: Regional Decimal Formats

<xsl:stylesheet version="2.0" xmlns:xsl="http://www.w3.org/1999/XSL/Transform">
  <!-- Default US format: comma for grouping, period for decimal -->
  <xsl:decimal-format name="us" decimal-separator="." grouping-separator="," />

  <!-- German format: period for grouping, comma for decimal -->
  <xsl:decimal-format name="de" decimal-separator="," grouping-separator="." />

  <xsl:template match="/">
    <!-- Outputs: 1,234,567.89 -->
    <xsl:value-of select="format-number(1234567.89, '#,##0.00', 'us')" />

    <!-- Outputs: 1.234.567,89 -->
    <xsl:value-of select="format-number(1234567.89, '#.##0,00', 'de')" />
  </xsl:template>
</xsl:stylesheet>

The third argument refers to the name attribute of the <xsl:decimal-format> definition. When omitted, the default decimal format is used.

Formatting Dates with format-date()

The format-date() function transforms an xs:date value into a localized string using pattern tokens and specific regional arguments.

Syntax

format-date($value, $picture, $language?, $calendar?, $country?)
  • $value: The input date (must be xs:date or castable to it).
  • $picture: The formatting pattern defining components like day ([D]), month ([M]), and year ([Y]).
  • $language: The ISO 639 language code (e.g., 'en', 'fr', 'de').
  • $calendar: The calendar model (typically 'AD' for Gregorian).
  • $country: The ISO 3166 country code (e.g., 'US', 'GB', 'DE').

Example: Localized Date Formatting

<xsl:stylesheet version="2.0" 
    xmlns:xsl="http://www.w3.org/1999/XSL/Transform"
    xmlns:xs="http://www.w3.org/2001/XMLSchema">

  <xsl:variable name="date" select="xs:date('2023-10-05')"/>

  <xsl:template match="/">
    <!-- English (US): October 5, 2023 -->
    <xsl:value-of select="format-date($date, '[MNn] [D], [Y]', 'en', (), 'US')"/>

    <!-- French (France): 5 octobre 2023 -->
    <xsl:value-of select="format-date($date, '[D] [MNn] [Y]', 'fr', (), 'FR')"/>

    <!-- German (Germany): 5. Oktober 2023 -->
    <xsl:value-of select="format-date($date, '[D]. [MNn] [Y]', 'de', (), 'DE')"/>
  </xsl:template>
</xsl:stylesheet>

In the picture string, [MNn] outputs the full name of the month localized to the provided $language parameter.

Formatting Times and Combined DateTimes

XSLT 2.0 includes two companion functions that share the exact same localization parameters as format-date():

  • format-time($value, $picture, $language?, $calendar?, $country?): Formats an xs:time value.
  • format-dateTime($value, $picture, $language?, $calendar?, $country?): Formats an xs:dateTime value.

Both functions allow components like AM/PM indicators ([P]) or weekday names ([FNn]) to be localized to the target region defined in the language and country arguments.
