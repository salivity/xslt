Round, Floor, and Ceiling Functions in XSLT

In XSLT transformations, managing decimal precision and rounding numbers to integers is a common arithmetic requirement. Standard XPath provides three primary numeric functions for this purpose: round(), floor(), and ceiling(). This article provides a direct overview of what each function does, how they differ in mathematical direction, and how to implement them within XSLT stylesheets.

The floor() Function

The floor() function returns the largest integer that is not greater than the provided numeric argument. In standard mathematical terms, it always rounds a number downward toward negative infinity.

  • Syntax: floor(number)
  • Behavior: Regardless of how close a decimal is to the next whole integer, floor() drops down to the nearest lower integer.

Examples:

  • floor(4.9) returns 4
  • floor(4.1) returns 4
  • floor(-4.1) returns -5 (because -5 is less than -4.1)

floor() is frequently used in XSLT when calculating zero-based index offsets, converting measurement units where fractions must not count toward the next unit, or managing discrete grid calculations.

The ceiling() Function

The ceiling() function produces the opposite result of floor(). It returns the smallest integer that is not less than the argument, rounding upward toward positive infinity.

  • Syntax: ceiling(number)
  • Behavior: If there is any fractional component greater than zero, the value rounds up to the next integer.

Examples:

  • ceiling(4.1) returns 5
  • ceiling(4.9) returns 5
  • ceiling(-4.9) returns -4 (because -4 is greater than -4.9)

A primary use case for ceiling() in XSLT is UI pagination. For example, if you divide 21 total items by a page size of 5 items, the division yields 4.2. Applying ceiling(21 div 5) calculates that 5 total pages are required to display all records.

The round() Function

The round() function rounds a number to the nearest integer based on standard rounding rules.

  • Syntax: round(number)
  • Behavior:
    • If the fractional part of the number is less than 0.5, it rounds down.
    • If the fractional part is greater than or equal to 0.5, it rounds toward positive infinity.

Examples:

  • round(4.4) returns 4
  • round(4.5) returns 5
  • round(4.6) returns 5
  • round(-4.5) returns -4 (rounds toward positive infinity for .5 ties in standard XPath 1.0/2.0)
  • round(-4.51) returns -5

round() is the standard choice for general display purposes, statistical summaries, and basic financial estimations where values should reflect the closest whole representation.

Practical XSLT Implementation

In an XSLT template, these functions are called directly within XPath expressions, such as inside <xsl:value-of> or <xsl:variable> elements:

<xsl:template match="product">
  <div class="pricing-summary">
    <!-- Round to nearest whole dollar -->
    <p>Estimated Cost: $<xsl:value-of select="round(price)" /></p>
    
    <!-- Round up shipping boxes -->
    <p>Boxes Needed: <xsl:value-of select="ceiling(weight div 10)" /></p>
    
    <!-- Base tier calculation -->
    <p>Tier Level: <xsl:value-of select="floor(rating)" /></p>
  </div>
</xsl:template>

If an argument cannot be converted to a valid number, all three functions return NaN (Not a Number). If the input is empty or omitted, standard XSLT processors will trigger an error.
