Using Anonymous Functions in XSLT 3.0

XSLT 3.0 integrates XPath 3.0 and 3.1 capabilities, introducing higher-order functions that allow developers to create and execute anonymous functions—commonly known as lambdas—directly within expressions. This article explains the core syntax for declaring anonymous functions, demonstrates how to invoke them immediately or through variables, and highlights their practical application alongside standard higher-order functions like fn:filter and fn:for-each.

Syntax of an Anonymous Function

An anonymous function is defined inline using the function keyword, followed by a parenthesized parameter list, an optional return type declaration, and a function body enclosed in curly braces.

The general syntax is:

function($parameter as type, ...) as return-type { expression }

Type annotations for parameters and the return type are optional. If omitted, they default to item()*.

function($x) { $x * 2 }

Assigning Lambdas to Variables

Anonymous functions can be bound to variables using <xsl:variable> or <xsl:param>. Once stored, the variable acts as a callable function reference.

<xsl:variable name="square" select="function($n as xs:integer) as xs:integer { $n * $n }"/>

To invoke the function through the variable, append parentheses containing the arguments directly to the variable reference:

<xsl:value-of select="$square(5)"/>
<!-- Output: 25 -->

Immediate Invocation

You can define and invoke an anonymous function in a single expression without assigning it to a variable. Wrap the function definition in parentheses before passing arguments:

(function($a, $b) { $a + $b })(10, 20)
<!-- Returns: 30 -->

Passing Lambdas to Higher-Order Functions

A primary use case for anonymous functions in XSLT 3.0 is passing custom logic directly to built-in higher-order functions such as fn:for-each, fn:filter, and fn:fold-left.

Example: Transforming Sequences with fn:for-each

Instead of creating a separate named xsl:function, you can supply an inline transformation:

<xsl:variable name="numbers" select="1 to 5"/>
<xsl:variable name="doubled" select="for-each($numbers, function($n) { $n * 2 })"/>
<!-- Result: (2, 4, 6, 8, 10) -->

Example: Filtering Data with fn:filter

Anonymous functions acting as predicates must return a boolean value:

<xsl:variable name="words" select="('apple', 'banana', 'fig', 'pear')"/>
<xsl:variable name="longWords" select="filter($words, function($w) { string-length($w) gt 4 })"/>
<!-- Result: ('apple', 'banana') -->

Variable Scoping and Closures

Anonymous functions in XSLT 3.0 act as closures. They retain access to variables declared in their enclosing lexical scope:

<xsl:variable name="factor" select="3"/>
<xsl:variable name="multiplier" select="function($n) { $n * $factor }"/>

<xsl:value-of select="$multiplier(10)"/>
<!-- Output: 30 -->

In this case, the lambda captures $factor from the stylesheet context and evaluates correctly when invoked.
