Using array:for-each and array:filter in XSLT 3.0

XSLT 3.0 natively supports XPath 3.1 data models, introducing arrays as first-class items alongside traditional XML sequences and trees. This article covers how to work with these structures using the higher-order functions array:for-each() and array:filter(), explaining their functional execution, syntax, and how to chain them together to transform data without side effects.

Understanding Arrays in XSLT 3.0

Unlike sequences in XSLT, which flatten automatically when nested, an array (array(*)) is a single item that can contain other items, including sequences and nested arrays. To use array functions, declare the array namespace in your stylesheet:

xmlns:array="http://www.w3.org/2005/xpath-functions/array"

Array indexes are 1-based, and each position in an array is called a member.

Transforming Items with array:for-each()

The array:for-each() function transforms each member of an array by applying an anonymous or named function, returning a new array containing the results.

Signature

array:for-each($array as array(*), $action as function(item()*) as item()*) as array(*)

How It Works

  1. Iterates through the input array in order.
  2. Passes each member (which may be a sequence) as an argument to the callback function.
  3. Packages the returned results into a new array of the same length.

Example

<xsl:stylesheet xmlns:xsl="http://www.w3.org/1999/XSL/Transform"
                xmlns:array="http://www.w3.org/2005/xpath-functions/array"
                version="3.0">

    <xsl:variable name="numbers" select="[1, 2, 3, 4, 5]"/>

    <!-- Doubles each member in the array -->
    <xsl:variable name="doubled" 
                  select="array:for-each($numbers, function($x) { $x * 2 })"/>

    <!-- Result: [2, 4, 6, 8, 10] -->
</xsl:stylesheet>

Selecting Items with array:filter()

The array:filter() function tests each member of an array against a predicate function and returns a new array containing only the members that evaluate to true.

Signature

array:filter($array as array(*), $function as function(item()*) as xs:boolean) as array(*)

How It Works

  1. Iterates sequentially over the members of $array.
  2. Passes each member to $function.
  3. Retains the member if the function returns true(), drops it if false().

Example

<xsl:stylesheet xmlns:xsl="http://www.w3.org/1999/XSL/Transform"
                xmlns:array="http://www.w3.org/2005/xpath-functions/array"
                version="3.0">

    <xsl:variable name="numbers" select="[1, 2, 3, 4, 5, 6]"/>

    <!-- Filters for even numbers -->
    <xsl:variable name="evens" 
                  select="array:filter($numbers, function($x) { $x mod 2 = 0 })"/>

    <!-- Result: [2, 4, 6] -->
</xsl:stylesheet>

Combining array:filter() and array:for-each()

Because both functions accept and return array instances, you can chain them using the XPath 3.1 arrow operator (=>). This pattern enables clean functional pipelines that filter input data before mapping it to a final structure.

<xsl:stylesheet xmlns:xsl="http://www.w3.org/1999/XSL/Transform"
                xmlns:array="http://www.w3.org/2005/xpath-functions/array"
                version="3.0">

    <xsl:variable name="scores" select="[45, 78, 92, 55, 88, 30]"/>

    <!-- Filter scores >= 60, then convert to grade strings -->
    <xsl:variable name="passingGrades" select="
        $scores 
        => array:filter(function($score) { $score ge 60 })
        => array:for-each(function($score) { concat('Score: ', $score) })
    "/>

    <!-- Result: ['Score: 78', 'Score: 92', 'Score: 88'] -->
</xsl:stylesheet>
