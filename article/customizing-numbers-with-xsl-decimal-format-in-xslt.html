Customizing Numbers with xsl:decimal-format in XSLT

This article explains how the <xsl:decimal-format> element controls numeric and currency representations during an XSLT transformation. By defining custom separators, symbols, and formatting characters, this element works in conjunction with the XPath format-number() function to format raw numeric data into localized strings, such as European currency notations or non-standard number patterns.

How <xsl:decimal-format> Works

The <xsl:decimal-format> element is a top-level element placed directly inside <xsl:stylesheet> or <xsl:transform>. It establishes the rules for parsing pattern characters supplied to the format-number() function.

By default, format-number() follows Western conventions: a period (.) denotes the decimal point, and a comma (,) denotes the grouping (thousands) separator. The <xsl:decimal-format> element overrides these defaults globally or provides named rules for specific formatting needs.

Key Attributes of <xsl:decimal-format>

  • name: An optional identifier. If specified, the format must be referenced by name in format-number(). If omitted, the definition overrides the default format.
  • decimal-separator: Specifies the character separating integer and fractional parts (default is .).
  • grouping-separator: Specifies the character separating digit groups (default is ,).
  • minus-sign: The character indicating negative values (default is -).
  • percent: The character indicating a percentage (default is %).
  • per-mille: The character indicating a per-mille rate (default is ‰).
  • zero-digit: The character representing the digit zero (default is 0).
  • digit: The character used in the picture string to represent an optional digit (default is #).
  • pattern-separator: The character that separates positive and negative sub-patterns within a format pattern (default is ;).
  • NaN: The string displayed when the input is not a valid number (default is NaN).

Customizing Currency Formats

While <xsl:decimal-format> dictates characters like the decimal separator and grouping marker, actual currency symbols (such as $, €, or £) are placed directly within the pattern string parameter of the format-number() function.

For example, European currencies commonly use a comma as the decimal separator and a period or space as the thousands separator. You can configure a custom format to support this layout:

<xsl:stylesheet version="1.0" xmlns:xsl="http://www.w3.org/1999/XSL/Transform">
  
  <!-- Define European numeric notation -->
  <xsl:decimal-format name="european" 
                      decimal-separator="," 
                      grouping-separator="." />

  <xsl:template match="product">
    <!-- Format: 1234567.89 becomes € 1.234.567,89 -->
    <xsl:value-of select="format-number(price, '€ #.##0,00', 'european')" />
  </xsl:template>

</xsl:stylesheet>

Positive and Negative Formatting

You can define separate representations for positive and negative numbers by using the pattern-separator (defaulting to ;) inside the pattern string:

<xsl:value-of select="format-number(balance, '$#,##0.00;($#,##0.00)')" />

In this case, a positive value displays as $1,500.00, while a negative value automatically formats as ($1,500.00).

Best Practices

  • Use Named Formats for Multi-Currency Outputs: When an XSLT transformation handles multiple locales or currencies simultaneously, define distinct, named formats (e.g., name="de" and name="us") instead of relying solely on the default format.
  • Match Input Numbers to Standard Formats: The raw XML values passed into format-number() must be valid numbers (using standard periods for decimals) before the formatting pattern can be applied.
