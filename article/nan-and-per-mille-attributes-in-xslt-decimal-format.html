nan and per-mille Attributes in XSLT Decimal Format

In XSLT, the xsl:decimal-format element controls how the format-number() function interprets formatting patterns and outputs numeric values. Within this definition, the nan attribute specifies the fallback string displayed when a target value is not a valid number, while the per-mille attribute defines the character used to represent parts per thousand (‰) in both pattern matching and output. Together, they allow developers to handle invalid data gracefully and localize specialized percentage-like calculations.

The Role of xsl:decimal-format

The xsl:decimal-format element establishes the symbols used by the XPath format-number() function. When transforming XML to HTML, text, or other XML formats, standard numbering conventions vary between locales and use cases. Defining custom decimal formats ensures that numbers, errors, and mathematical notations conform to the required output standard.

The nan Attribute

The nan attribute determines what string is output when the numeric expression passed to format-number() evaluates to NaN (Not a Number).

  • Default Value: "NaN"
  • Purpose: By default, if a non-numeric value or an invalid mathematical result (such as dividing zero by zero) is processed, XSLT renders literal text: NaN. The nan attribute allows this representation to be customized to user-friendly or localized strings such as "N/A", "Not Applicable", "-", or "None".
  • Example: 
    <xsl:decimal-format name="custom" nan="N/A" />
    Evaluating format-number('invalid_string', '#,##0.00', 'custom') will output N/A instead of NaN.

The per-mille Attribute

The per-mille attribute defines the character that represents a per-mille sign (parts per thousand) in a format pattern.

  • Default Value: ‰ (Unicode character &#x2030;)
  • Purpose: Similar to how the percent symbol (%) multiplies a fraction by 100 and appends the sign, a per-mille character multiplies the input number by 1,000 and appends the specified symbol. The per-mille attribute allows you to redefine which character triggers this behavior in the pattern and which character appears in the resulting document. This is useful when working with specific encodings, environments lacking standard Unicode per-mille support, or alternate cultural notations.
  • Example: 
    <xsl:decimal-format name="promille" per-mille="m" />
    Evaluating format-number(0.025, '#,##0m', 'promille') multiplies 0.025 by 1,000 to produce 25m.

Summary of Usage

Both attributes give developers precise control over presentation logic:

  • Use nan to replace system error indicators with clean, readable fallback text when data is missing or corrupted.
  • Use per-mille to manage parts-per-thousand mathematical representations according to specific locale, character set, or display requirements.
