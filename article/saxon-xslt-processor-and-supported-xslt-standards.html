Saxon XSLT Processor and Supported XSLT Standards

The Saxon XSLT processor is an industry-standard engine developed by Saxonica for transforming XML documents and querying structured data. This article explores what the Saxon processor is, explains its primary use cases and available editions, and provides a detailed breakdown of the XSLT standards it supports, ranging from XSLT 1.0 to modern XSLT 3.0 and emerging draft specifications.

What is the Saxon XSLT Processor?

Saxon is a cross-platform processing engine designed for XSLT (Extensible Stylesheet Language Transformations), XQuery, and XML Schema validation. Originally created by Michael Kay, who served as the editor of the W3C XSLT specifications, Saxon is widely regarded as the reference implementation for modern XML technologies.

Saxon processes XML documents by taking an input source, applying stylesheets or queries, and outputting formatted structures such as other XML documents, HTML, JSON, or plain text. It runs natively on the Java platform and the .NET framework, with C/C++, PHP, and Python bindings available through Saxon/C.

Saxonica distributes the processor in three primary tiers:

  • Saxon-HE (Home Edition): An open-source edition covering basic, core functionality for standard transformations.
  • Saxon-PE (Professional Edition): A commercial package providing enhanced capabilities, including support for EXPath extension libraries and external extension functions.
  • Saxon-EE (Enterprise Edition): The full commercial suite with enterprise-grade features such as schema-aware transformations, streaming processing for very large files, byte-code generation, and multi-threading.

Supported XSLT Versions

Saxon is notable for its continuous alignment with W3C standards, supporting multiple iterations of the XSLT specification.

XSLT 1.0

Saxon provides complete backward compatibility for XSLT 1.0 stylesheets. While Saxon’s core architecture is built around later standard versions, it includes a dedicated 1.0 compatibility mode. When a stylesheet specifies version="1.0", Saxon adjusts its evaluation behavior—such as data-type conversions and node-set handling—to conform to the older 1999 specification.

XSLT 2.0

Saxon was the premier reference implementation for the W3C XSLT 2.0 recommendation, which became official in 2007. Saxon fully supports all XSLT 2.0 requirements across all editions. This includes regular expressions, strong typing via XML Schema, grouping elements with xsl:for-each-group, user-defined stylesheet functions, and support for multiple output documents via xsl:result-document.

XSLT 3.0

Modern releases of Saxon (version 9.8 and later, including Saxon 10, 11, and 12) provide complete implementation of the W3C XSLT 3.0 Recommendation finalized in 2017. Supported features include:

  • Streaming: Processing documents larger than available memory without loading the complete node tree (available in Saxon-EE).
  • Packages: Modular stylesheet components for better library management and code reuse.
  • JSON Support: Direct parsing, manipulation, and output of JSON structures alongside XML.
  • Higher-Order Functions: Inline functions and dynamic function calls.
  • Text Assertions and Try/Catch: Enhanced error handling and schema validation integration.

While Saxon-HE supports basic XSLT 3.0 transformations, advanced components like streaming and bytecode optimization require Saxon-EE.

XSLT 4.0 (Draft)

Recent versions of Saxon, particularly Saxon 12, include experimental support for features currently being drafted by the W3C XSLT Next Community Group for XSLT 4.0. These experimental additions include advanced array and map manipulation syntax, expanded built-in functions, and modern functional programming extensions, allowing developers to test forward-looking capabilities before standard finalization.
