XSLT 2.0 string-join Function for Delimited Lists

This article explains the purpose and practical application of the string-join() function introduced in XPath and XSLT 2.0. It covers how the function simplifies formatting delimited lists from XML data, eliminates the need for cumbersome conditional logic, and improves stylesheet readability and performance.

The Purpose of string-join()

In XSLT 2.0, the primary purpose of the string-join() function is to concatenate a sequence of strings into a single string, inserting a specified delimiter between each item. When transforming XML elements or attributes into delimited formats such as Comma-Separated Values (CSV), natural language lists, or parameter strings, managing delimiters between items is a standard requirement.

Before XSLT 2.0, creating a delimited list required iterating through nodes using <xsl:for-each> and manually checking <xsl:if test="position() != last()"> to prevent a trailing delimiter after the final element. The string-join() function replaces this verbose logic with a single, declarative XPath expression.

Syntax and Behavior

The string-join() function uses the following signature:

fn:string-join($arg1 as xs:anyAtomicType*, $arg2 as xs:string) as xs:string
  • $arg1: A sequence of atomic values or strings to be joined.
  • $arg2: The separator string inserted between each item.

The function evaluates the sequence and handles edge cases automatically:

  • If the sequence contains multiple items, the separator is inserted only between items. No separator is placed before the first item or after the last item.
  • If the sequence contains a single item, the function returns that item without the separator.
  • If the sequence is empty, the function returns an empty string ("").

Example Implementation

Given the following XML source:

<authors>
    <name>Alice</name>
    <name>Bob</name>
    <name>Charlie</name>
</authors>

In XSLT 1.0, joining these names required manual positioning logic:

<xsl:for-each select="authors/name">
    <xsl:value-of select="."/>
    <xsl:if test="position() != last()">, </xsl:if>
</xsl:for-each>

In XSLT 2.0, the same result is achieved using string-join() in a single line:

<xsl:value-of select="string-join(authors/name, ', ')"/>

Output:

Alice, Bob, Charlie

Key Advantages

  • Cleaner Stylesheets: Reduces multi-line procedural iteration to a concise, functional XPath call.
  • Boundary Handling: Automatically resolves the "fencepost problem" (trailing separators) without requiring index calculations like position() and last().
  • Dynamic Sequences: Works directly on sequences generated on the fly (e.g., using XPath expressions or functions like tokenize()), not just static nodes in the source XML document.
